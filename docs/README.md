# Warga App Documentation

Folder ini berisi seluruh dokumentasi terkait pengembangan aplikasi Warga App.

## Struktur Direktori

- `api/` - Dokumentasi endpoint API yang digunakan.
- `design/` - Markdown desain per halaman/fitur.
- `specs/` - Spesifikasi Frontend (komponen, logic, state management).
- `general/` - Dokumentasi pendukung lainnya.
